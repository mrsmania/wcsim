  • The page finally looks like what it is: a place where other people are. Everything else is one tap behind a bar.
  • The alert strip is the only history on the page, and it is absent when nothing is waiting, so the page is never padded with what you have already done.
  • A sheet is a second surface to design and to keep accessible, and the lobby is empty most days, so the page's first impression depends on other people.

•What all five change, whichever wins

  • The lobby reads as a lobby. A section heading rather than a 10px caption, a live dot with a seat count beside it, seat pips on every row so the room's state is readable without counting words, and Refresh as a real button with an icon that says when it last looked.
  • The name row goes. It becomes "Mario 4-2" beside the page title with a small Change name button, which is a line rather than a card.
  • Section rules. Three visible headings, the same treatment the career page and the album already use, so the page says what its parts are.
  • The 100-word introduction goes. What a versus match is belongs on the empty state and in the sheet or the menu, not above the controls every time.
  • Nothing here needs the referee rebuilt or a migration. Every setting still reaches the same create call, and the lobby and duel reads are unchanged.
