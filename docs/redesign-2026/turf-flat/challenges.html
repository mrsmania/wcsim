Every challenge is permanent

Each one is completable once, worth a fixed award, and stays on the list until you get it. There is no weekly rotation and no expiry, so nothing is ever missed by not playing.

The rotating layer (a few challenges singled out for the day at a higher reward, with a strip on the build page and chips under the run ladder) is a separate roadmap item. It reads this same catalogue, so it can arrive later without changing anything here.
